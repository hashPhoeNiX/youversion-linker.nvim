*youversion-linker.txt*  YouVersion Linker plugin for Neovim

==============================================================================
INTRODUCTION                                                    *youversion-linker*

YouVersion Linker is a Neovim plugin for quickly inserting Bible passages and links from YouVersion into your notes. It provides popup menus for selecting Bible versions and supports Markdown and text files.

==============================================================================
INSTALLATION                                                   *youversion-linker-install*

Requirements:
- Neovim >= 0.11.1
- pup (https://github.com/ericchiang/pup) for HTML parsing
- lua-cjson (optional, for JSON parsing)

Install with your favorite plugin manager, e.g. with lazy.nvim:

>
    {
      "yourusername/youversion-linker.nvim",
      config = function()
        require("youversion-linker").setup()
      end,
    }

==============================================================================
CONFIGURATION                                                  *youversion-linker-config*

Setup the plugin in your init.lua:

>
    require("youversion-linker").setup({
      debounce_delay = 50,
      filetypes = { "*.md", "*.txt" },
      bible_versions = {
        KJV = { enabled = true },
        NIV = { enabled = true },
        AMP = { enabled = false },
      },
      -- See lua/youversion-linker/config.lua for all options
    })

==============================================================================
USAGE                                                          *youversion-linker-usage*

Type a Bible reference with a trigger character:

    >John 3:16
    @Psalm 23:1
    ^Romans 8:28

A popup menu will appear to select the Bible version. Use <Tab>, <S-Tab>, or arrow keys to navigate. Press <CR> or <Space> to insert the passage. <Esc> closes the menu.

Manual trigger:

>
    :lua require("youversion-linker").manual_trigger()

==============================================================================
COMMANDS & FUNCTIONS                                           *youversion-linker-commands*

- `require("youversion-linker").setup({ ... })`   Set up the plugin.
- `require("youversion-linker").manual_trigger()` Manually open the popup menu.

==============================================================================
TROUBLESHOOTING                                                *youversion-linker-troubleshooting*

- Ensure `pup` is installed and in your $PATH.
- If the popup does not appear, check your filetype and trigger character.
- For debugging, set NVIM_PLUGIN_DEBUG=1 in your environment.
